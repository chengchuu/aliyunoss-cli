No-network example

Configure an Alibaba Cloud OSS client

Enter non-secret sample settings and create a client through the package root API. The example displays safe configuration fields and never calls an upload method or sends a network request.

What this demonstrates

The example imports aliyunoss-cli from the package root, constructs the re-exported Alibaba Cloud OSS client, and reports the safe settings selected in the form.
